# .github

The `reuben-ssg` organization's profile and brand files.

- `profile/README.md` is the page shown at [github.com/reuben-ssg](https://github.com/reuben-ssg).
- `brand/` holds the logo, icon, avatar, mascot artwork and color palette; see [`brand/README.md`](brand/README.md).

Made with love by [@nickvigilante](https://github.com/nickvigilante).
